Subtitle tidak terbaca? Tempel manual

Cara cadangan tanpa batas kuota: 1) buka situs unduh subtitle, 2) unduh file .srt/.vtt, 3) pilih file itu di bawah.

Link videomu otomatis disalin. Jika kolom di situs kosong, tempel saja (Ctrl+V). Hati-hati dengan iklan di situs itu: jangan pasang aplikasi atau ekstensi apa pun.

Subtitle hanya disimpan sementara di memori selama halaman ini terbuka, tidak disimpan di perangkat Anda.
